Система автоматического резервного копирования данных для Linux, написанная на языке Bash. Проект реализует полный цикл управления бэкапами: от архивации до автоматической очистки старых копий.

Основные возможности:

    Архивация: Использование tar и gzip для сжатия данных.
    Инкрементальность: Создание копий только изменившихся файлов для экономии места.
    Ротация: Хранение нескольких версий бэкапов и автоматическое удаление устаревших архивов.
    Контроль качества: Проверка целостности созданных архивов.
    Автоматизация: Настройка регулярного запуска через планировщик cron.
    Журналирование: Ведение детальных логов всех операций и ошибок.

Стек технологий: Bash, Linux, Git, Cron.
